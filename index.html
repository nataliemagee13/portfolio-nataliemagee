Swiftie Song Finder

For my web development class, I designed and built Swiftie Song Finder, a Taylor Swift song recommender for fans who can't decide what to listen to. Users pick from six moods and get a song suggestion with its album, try again without repeats, hit "Surprise me," and save favorites that stay after a refresh.

I wrote a full project plan before using AI for any code, then built the core feature first and added extras once it worked. The project helped me build skills in JavaScript, working with JSON data, saving user data with localStorage, and keeping a project focused on what the user actually needs.
